## 🚀 Features & Architecture

This portfolio is designed with a sleek, classy aesthetic and built for optimal performance. It consists of the following modular sections:
* **Hero/Home:** An engaging introduction and quick access to my professional resume (`Rishi-Rana.pdf`).
* **About:** Details on my background, education, and current journey toward a software engineering role.
* **Skills:** A comprehensive breakdown of my modern tech stack, spanning frontend, backend, and DevOps.
* **Projects:** Showcases of my best work, integrating full-stack technologies and Generative AI.

## 🛠️ Tech Stack

The project leverages a modern frontend tooling ecosystem:

* **Styling:** Tailwind CSS for a responsive, utility-first design.

## ⚙️ Local Development

To run this project locally on your machine, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone <your-repo-url>
   cd my-portfolio
   ```
2. **Install dependencies:**
   ```bash
   npm install
   ```
3. **Start the development server:**
   ```bash
   npm run dev
   ```
4. **Build for production:**
   ```bash
   npm run build
   ```

## 🌐 Deployment

This application is currently deployed and hosted on **Vercel**. 
To deploy your own instance directly from the terminal, you can use the Vercel CLI:
```bash
npm i -g vercel
vercel
```
